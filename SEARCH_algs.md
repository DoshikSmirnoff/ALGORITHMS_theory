## Линейный поиск (Linear Search)
_- расширенная версия реализации оператора `in`_
Суть алгоритма заключается в том, чтобы перебрать массив и вернуть индекс первого вхождения элемента, когда он найден

```
def LinearSearch(lys, element):
    for i in range (len(lys)):
        if lys[i] == element:
            return i
    return -1
print(LinearSearch([1,2,3,4,5,2,1], 2)) # -> 1
```

Или вариант реализации при помощи ипользования `enumerate()`:
```
def linear_search(arr, target):
    for i, item in enumerate(arr):
        if item == target:
            return i
        return -1

numbers = [64, 34, 25, 12, 22, 11, 90]
target = 22
result = linear_search(numbers, target)
print(f"Элемент {target} найден на позиции {result}" if result != -1 else f"Элемент {target} не найден")
```
#### Временная сложность:
O(n) - так как в худшем случае придется проверить все `n` элементов массива

#### Преимущества: 
- Работает с неотсортированными массивами
- Простота реализации
- Эффективен при работе с маленькими массивами
- Не требует дополнительной памяти

#### Недостатки:
- Неэффективен при работе с большими массивами
- Линейная временная сложность

## Бинарный поиск (Binary Search)
Данный алгоритм осуществляет поиск путем многократного деления отсортированного массива пополам, сужая область поиска

В массиве мы ищем значение `val`, сравнивая его со средним элементом массива `mid`
Если `mid` — это искомый элемент (в лучшем случае), мы возвращаем его индекс
Если нет, мы определяем, в какой половине массива мы будем искать `val` дальше, основываясь на том, меньше или больше значение `val` значения `mid`, и отбрасываем вторую половину массива
Затем мы рекурсивно или итеративно выполняем те же шаги, выбирая новое значение для `mid`, сравнивая его с `val` и отбрасывая половину массива на каждой итерации алгоритма

Алгоритм бинарного поиска осуществляется как итеративно, так и рекурсивно. Рекурсия обычно медленнее, так как требует выделения дополнительных кадров стека

Итеративная реализация бинарного поиска:
```
def BinarySearch(lys, val):
    first = 0
    last = len(lys)-1
    index = -1
    while (first <= last) and (index == -1):
        mid = (first+last)//2
        if lys[mid] == val:
            index = mid
        else:
            if val < lys[mid]:
                last = mid -1
            else:
                first = mid +1
    return index

BinarySearch([10,20,30,40,50], 20) # -> 1
```

На каждой итерации алгоритм выполняет одно из следующих действий:
- Возврат индекса текущего элемента
- Поиск в левой половине массива
- Поиск в правой половине массива

#### Временная сложность:
O(log n) - так как на каждой итерации наш массив делится на две части

#### Недостатки: 
Если в массиве имеется несколько вхождений элемента, то он возвращает индекс не первого элемента, а ближайшего к середине

## Другие алгоритмы поиска
1) Jump Search
_Тоже работает с отсортированным массивом и также делит его на подмассивы_
Поиск происходит не постепенно по элементам массива, а скачкообразно (задается размер "прыжка")
Например, имеется массив `lys` и размер прыжка `jump` - алгоритм будет рассматривать элементы в следующем порядке: `lys[0]`, `lys[0+jump]`, `lys[0+2jump]`, `lys[0+3jump]` и так далее
С каждым прыжком мы сохраняем предыдущее значение и его индекс. Когда мы находим множество значений (блок), где `lys[i] < element < lys[i + jump]`, мы выполняем линейный поиск с `lys[i]` в качестве самого левого элемента и `lys[i + jump]` в качестве самого правого элемента в нашем массиве

2) Поиск Фибоначчи
_Использует числа Фибоначчи для вычисления размера блока или диапазона поиска на каждом шаге_
